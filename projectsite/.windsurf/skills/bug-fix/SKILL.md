Instructions for the skill go here. Provide relative paths to other resources in the skill directory as needed.
When fixing a bug:
1. Ask for the full error traceback or screenshot 
   first — do not guess the problem
2. Read the affected file completely before touching 
   anything
3. Identify and explain the root cause first, 
   wait for my confirmation before fixing
4. Apply the minimal fix only — do not refactor 
   or change unrelated code
5. After fixing, explain what caused the bug and 
   what was changed
6. Tell me exactly what to do to test the fix
