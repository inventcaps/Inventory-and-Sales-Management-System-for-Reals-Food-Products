When adding a new feature:
1. Check existing models.py, urls.py, and views.py 
   first before writing any code
2. Show me the plan and list of files to be changed 
   — wait for my approval before proceeding
3. Implement one step at a time, not all at once

5. Never modify unrelated files
6. After implementing, tell me what to test
